# Personal Expense Tracker

A Python-based expense tracking application built with Streamlit, Pandas, and Plotly to help users manage expenses, monitor budgets, and understand their spending habits.

## Links

- **Live App:** https://personal-expense-tracker-fatema-ghanem.streamlit.app/
- **Video Demo:** https://drive.google.com/file/d/1K_CC0o5ur2JdUto8KX7scprmDk2gtPKX/view?usp=sharing

## Features

- Import, edit, and download expense records using CSV files.
- Add and manage daily expenses.
- View total expenditure, average daily spending, and category breakdowns.
- Set monthly budgets and receive spending alerts.
- Forecast end-of-month spending.
- Filter expenses by category and view all records.

## Technologies

- Python
- Streamlit
- Pandas
- Plotly
